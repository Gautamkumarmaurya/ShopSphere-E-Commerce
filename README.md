# ShopSphere

Premium dark cinematic e-commerce frontend built with React, Vite, JavaScript and Tailwind CSS.

## Features
- Responsive sticky navbar + mobile menu
- DummyJSON API product data
- Search, category filtering and sorting
- Product details/gallery + related products
- Context API cart with LocalStorage persistence
- Simulated login/signup with LocalStorage
- Frontend-only checkout simulation
- Loading skeletons, errors and empty states
- Accessible labels/focus states

## Run
npm install
npm run dev

## Build
npm run build
npm run preview

Authentication and payment are demo-only; no real credentials or payment data are processed.
